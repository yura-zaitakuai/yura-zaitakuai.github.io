はじめる前に

用意するのは、この2つだけ

  • ChatGPT（チャットジーピーティー）Googleアカウントで登録・無料版でOK
  • Canva（キャンバ）Googleアカウントで登録・無料プランでOK

  • Canvaにログインして、ホーム画面が出ている

ChatGPTの無料版は、1日に作れる画像の枚数に上限があります（動画では4枚で上限になりました）。上限になったら、続きは次の日で大丈夫です。直したいところは、1回の指示にまとめて伝えると枚数を節約できます。

RECIPE01

好きな雰囲気を、AIに言葉にしてもらう

ステップ1　雰囲気を決める

使い方

  1. Pinterestなどで「インスタ 投稿 デザイン ナチュラル」のように、好みの雰囲気の言葉で検索します。
  2. 「いいな」と思うデザインを2〜3枚、スクリーンショットで撮ります。
  3. 下の「コピーする」を押して、ChatGPTの新しいチャットに貼り、スクリーンショットを一緒に入れて送ります。
  4. 色・余白・飾り・イラストのタッチが言葉で返ってきます。これが、このあと全部のページで使うデザインのルールになります。

参考の画像は、ほかの方が作った作品です。そのまま真似して作るためではなく、自分の好みを言葉にするためだけに使います。複数枚の共通点を言葉にしてから作るので、特定の1枚に似にくくなります。

新しいチャットで、スクリーンショットと一緒に送る
RECIPE 01｜好みを言葉にする
添付した画像は、私が「この雰囲気が好き」と思ったデザインの参考です。
真似をしたいのではなく、好みを言葉にしたいです。
複数の画像に共通する点を、次の項目で書き出してください。

・配色（背景／メイン／文字／アクセントを色コードで）
・余白の取り方、角の丸み、線の太さ
・飾りのモチーフ（植物、リボン、マスキングテープなど）
・イラストのタッチ（水彩、線画、フラットなど）
・全体の印象を表す言葉を3つ

特定の1枚にしかない特徴は入れないでください。

RECIPE02

最初の1枚、表紙を作る

ステップ2　表紙

使い方

  1. 下の「コピーする」を押して、RECIPE 01と同じチャットで送ります。
  2. 1分ほどで表紙の画像ができます。
  3. 色やイラストを変えたいときは「もう少し色をうすく」「イラストを花に」のように、そのまま言葉で伝えます。
  4. できた画像は、右上のボタンからダウンロードしておきます。

文字が「タイトルが入ります」になっているのは、わざとです。テンプレートは、買った人が自分の言葉に打ちかえて使うものなので、「ここに文字を入れてくださいね」と分かる形にしておきます。

同じチャットで続けて送る
RECIPE 02｜表紙を作る
上で書き出したデザインルールだけを使って、Instagram投稿テンプレートの
「表紙ページ」を画像で1枚作ってください。参考画像の構図は使わないでください。

・サイズ：縦長4:5
・中央に大きく「タイトルが入ります」
・その上に小さく「サブタイトルが入ります」
・下に帯で「ここにメインメッセージを入力」
・挿絵は下側に1〜2点。人物は入れない
・文字は日本語で、読みやすい丸ゴシック系

RECIPE03

表紙をもとに、残りのデザインを作ってもらう

ステップ3　ページを増やす

使い方

  1. 下の「コピーする」を押して、同じチャットに貼ります。
  2. {ここを入れ替える} のところを、作りたいページの種類に書きかえて送ります。
  3. できた画像を確認します。文字が1文字おかしい、数字がずれている、というところがあれば「ここの文字を直して」と伝えます。
  4. ダウンロードしたら、ページの種類を入れかえて、同じことをくり返します。

背景の色、タイトルの位置、飾り、イラストのタッチを表紙とそろえてくれます。1枚ずつ手で作ると何時間もかかるところを、種類を1か所書きかえるだけで進められます。

ページの種類

  • テキストだけ（タイトル＋大きな文章枠）
  • ポイント3つ（丸アイコン＋見出し＋説明）
  • 3ステップ（STEP01→02→03）＋POINT欄
  • 3つの要素の重なり図
  • テキスト＋写真を入れる枠
  • 番号つきリスト5項目
  • 4分割（見出し＋説明）＋メモ欄
  • チェックリスト5項目
  • Before／After比較
  • 番号つき3項目（横長の枠）
  • 締めのページ（いいね・保存・シェアのお願い）

動画では、表紙＋「テキストだけ」「ポイント3つ」「3ステップ」「Before／After比較」「4分割＋メモ欄」の6枚で作りました。実際に売るなら12枚や20枚のセットのほうが選んでもらいやすいので、慣れてきたら枚数を増やしてみてください。

同じチャットで、ページの種類を入れかえながら送る

添付画像（または上の表紙）と同じシリーズに見える、

ステップ4　Canvaで仕上げる

1枚の画像を、編集できるテンプレートに変える

  1. Canvaのホーム画面の「アップロード」→「ファイルをアップロード」で、ダウンロードした画像をまとめて入れます。
  2. 表紙の画像を開いて「新しいデザインで使用」を押します。画像と同じ大きさのデザインができます。
  3. 「ページを追加」を押して、残りの画像を1枚ずつ置きます。小さく入ったときは、角をつかんでページいっぱいまで広げます。
  4. 画像を選んだまま、上の「編集」→ツールの「マジックレイヤー」を押します。
  5. 30秒ほどで、文字・イラスト・背景に分かれます。文字をダブルクリックすると打ちかえられます。
  6. ほかのページでも、同じようにマジックレイヤーをかけていきます。

仕上げの小ワザ

  • 文字をまとめて変える：文字を1つ選び、Shiftキーを押しながらほかの文字もクリック。そのまま太字やフォントを変えると全部いっぺんに変わります。フォントは2種類までにしぼるとまとまって見えます。
  • 袋文字：文字が読みにくいときは、文字を選んで「エフェクト」→「袋文字」。色を白にして太さを上げると、くっきり読めます。
  • フレーム：「素材」で「フレーム」と検索して置いておくと、買った人が写真をドラッグするだけで枠の形に入ります。
  • 王冠マークの確認：フォントや素材に王冠がついていたら、ついていないものに変えます。無料プランで使う人が困らないようにするためです。

動かしているときに出る線は、「まん中です」「となりとそろっています」と教えてくれる目印です。この線に合わせて置くだけで、位置がきれいにそろいます。

RECIPE04

買ってくれた人に渡すページを作る

ステップ5　渡す準備

使い方

  1. 先に、Canvaでテンプレートの右上「共有」を押し、「リンクを知っている全員」「表示」にして「リンクをコピー」を押します。
  2. 下の「コピーする」を押して、ChatGPTの同じチャットで送ります。お渡しページの画像ができます。
  3. 画像をCanvaの新しいデザインに入れて、マジックレイヤーをかけます。
  4. まん中のボタンを選んで、リンクのボタン（または右クリック→「リンク」）から、コピーしておいたリンクを貼ります。
  5. 右上の「共有」→「ダウンロード」→「PDF（標準）」でダウンロードします。買ってくれた人に送るのは、このPDF1つです。

共有の設定は必ず「表示」にしてください。「編集」のままだと、買った人が元のデータを直接さわれてしまいます。買った人は、リンクを開いて左上の「ファイル」→「コピーを作成」を押すと、自分のCanvaで編集できるようになります。

同じチャットで続けて送る
RECIPE 04｜お渡しページを作る

RECIPE05

出品に使う商品画像の土台を作る

ステップ5　渡す準備

使い方

  1. 下の「コピーする」を押して、同じチャットで送ります。「6デザイン」のところは、作った枚数に書きかえてください。
  2. 左側に商品名、右側が空いた土台の画像ができます。
  3. Canvaに入れて、空いているところに、ダウンロードしておいたページの画像を並べます。

AIに全部のページが並んだ画像を丸ごと作らせると、ページ番号や文字がくずれやすくなります。土台だけ作ってもらい、実際のページを並べるほうが、買う人に「これが手に入る」と正しく伝わります。

同じチャットで続けて送る
RECIPE 05｜商品画像の土台を作る
同じシリーズのデザインで、販売ページに載せる商品画像の「土台」を画像で1枚作ってください。

・サイズ：正方形
・左側に「Instagram投稿テンプレート」「6デザイン」（作った枚数に書きかえる）「Canvaで簡単編集」
・右側の3分の2は、あとでページ画像を並べるので何も置かず空けておく
・色とイラストのタッチは表紙と揃える

どこで売る？

おすすめの販売サイトと、かかる手数料

  • BOOTHはじめての方におすすめ。手数料は売上の5.6％＋45円（1件ごと）
  • ココナラ人が多く、最初の1つを見つけてもらいやすい。販売手数料は22％（税込）
  • BASE自分のお店として作りこみたい方に。月額0円のプランは決済手数料3.6％＋40円と、サービス利用料3％
  • Etsy慣れてきたら海外にも。出品料が1点0.20ドル、取引手数料6.5％、ほかに決済の手数料
  • 最初の1つは、BOOTHかココナラから始めるのがおすすめです。
  • 値段は、同じくらいの枚数のテンプレートがいくらで並んでいるかを見て、そのまん中くらいにします。あとから変えられます。
  • 手数料を引いた金額が、手元に入るお金です。500円のテンプレートをBOOTHで売ると、手数料は73円、手元に入るのは427円が目安です。

手数料は2026年10月時点で調べたものです。変わることがあるので、出品する前に各サイトの案内で確認してください。AIで作ったものの扱いも、サイトごとにルールがあります。

出品する前に

AIで作って売るなら、守ってほしい3つ

  • ほかの人の作品をそのままAIに入れて「同じものを作って」と頼まない。作家さんやキャラクターの名前を入れて作らない。
  • 商品の説明に「著作権フリー」と書かない。「Canvaで文字や色を変えて使えます」と、できることをそのまま書く。
  • 色だけ変えたものを大量に並べない。次を作るなら、サロン向け・カフェ向けのように、使う人を変える。

出品するサイトごとに、AIで作ったものの扱いや手数料のルールがあります。出す前に、そのサイトの案内を一度読んでおいてください。
