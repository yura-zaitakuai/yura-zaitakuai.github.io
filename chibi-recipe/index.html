全体の地図

ちびキャラ1体を、3つの副業に使い回す流れ

はじめる前に

用意するのは、この2つだけ

  • ChatGPT（チャットジーピーティー）Googleアカウントで登録・無料版でOK
  • Canva（キャンバ）Googleアカウントで登録・無料プランでOK
  • ChatGPTにログインして、文字を打ちこむ画面が出ている
  • Canvaにログインして、ホーム画面が出ている

指示文の中の{ }のところは、自分の内容に書きかえて使います。ChatGPTの無料版は、1日に作れる画像の枚数に上限があります。上限になったら、続きは次の日で大丈夫です。

RECIPE01

主役のちびキャラを1体作る

最初にやること

使い方

  1. 下の「コピーする」を押して、ChatGPTの新しいチャットに貼ります。
  2. { }の中のモチーフ・性格・色を、自分の好きなものに書きかえて送ります。
  3. 1分ほどでキャラクターができます。「耳をもう少し小さく」「色をうすく」のように、直したいところは言葉でそのまま伝えます。
  4. 気に入ったら、画像をダウンロードしておきます。このチャットは閉じずに、最後まで使います。

すでにある有名なキャラクターや、作家さんの名前を入れて作るのはやめましょう。販売できなくなります。色を3色までにしておくと、小さく印刷しても、スタンプにしても、見やすくなります。

新しいチャットで送る
RECIPE 01｜ちびキャラを作る
オリジナルのちびキャラクターを1体、画像で作ってください。
グッズやLINEスタンプにして販売するためのキャラクターです。

・モチーフ：{白いくま}
・性格や雰囲気：{のんびり屋で、いつも眠そう}
・使う色：{白・うすい水色・こげ茶}の3色まで
・2頭身で、線は太め。フラットでシンプルな塗り
・正面を向いて立っている全身のポーズを1つ
・文字は入れない
・背景は透明にする（透過PNG）
・すでにある有名なキャラクターや作品には似せない

RECIPE02

ステッカー用のポーズを作る

①ステッカー販売

使い方

  1. 先に、BOOTHで「ステッカー」と検索して、どんな使い道のものが人気かを見ておきます。
  2. 下の「コピーする」を押して、RECIPE 01と同じチャットに貼ります。
  3. { }のポーズを、ステッカーの使い道に合うものに書きかえて送ります。
  4. できた画像をダウンロードします。

人気のステッカーは、絵の上手さよりも「何のために貼るか」がはっきりしています。文字はAIに入れてもらわず、あとからCanvaで入れます。言葉だけ変えた別の商品を、すぐ作れるようになるからです。

同じチャットで続けて送る
RECIPE 02｜ステッカー用のポーズ
さっきと同じキャラクターで、ステッカー用のイラストを1枚作ってください。
顔・体の形・色は変えないでください。

・ポーズ：{クッションを抱いて、すやすや眠っている}
・正方形
・文字は入れない
・背景は透明にする（透過PNG）
・小さく印刷しても分かるように、細かい飾りは入れない

①ステッカー販売　Canvaと出品

Canvaで文字を入れて、BOOTHに出す

  1. Canvaのホーム画面の「カスタムサイズ」で、正方形のデザインを作ります。大きさは、pixivFACTORYのステッカーのページに書いてある数字を入れます。
  2. 「素材」から丸い図形を選んで、画面いっぱいに広げます。うすい色にして、フチの線を太めにつけます。
  3. 「アップロード」からキャラクターの画像を入れて、丸の上のほうに置きます。
  4. 「テキスト」で、伝えたい言葉を入れます。大きい文字を1行、その下に小さい文字を1行です。
  5. 右上の「共有」→「ダウンロード」→「PNG」でダウンロードします。
  6. pixivFACTORYで「ステッカー」を選び、素材とサイズを決めて画像をアップロードします。プレビューで形を確認して保存します。
  7. 「BOOTHで販売する」を押して、商品名・説明・自分の利益を入れて公開します。
  • 画面を小さくしても、文字が読める
  • 文字は2行まで、色は3色までにおさまっている
  • 商品名に、買う人が検索しそうな言葉が入っている

手元に入るお金の目安：自分の利益を300円にすると、BOOTHの手数料（利益の5.6％＋1回の注文につき45円）を引いて、約240円です。手数料は2026年10月時点で調べたものなので、出品の前にBOOTHの案内で確認してください。

RECIPE03

スタンプのセリフとポーズを考えてもらう

②LINEスタンプ販売

使い方

  1. 先に、LINEのスタンプショップで、クリエイターズスタンプの人気ランキングを見ておきます。
  2. 下の「コピーする」を押して、同じチャットに貼ります。
  3. { }の「使う人」を書きかえて送ります。
  4. 8個のセリフとポーズが表で返ってきます。変えたいものがあれば「3番を別の言葉に」と伝えます。

使う人をはっきり決めると、その人が毎日送る言葉がそのままセリフになります。「見てね」と指さすポーズを1つ入れておくと、あとでスライドにも使えます。

同じチャットで続けて送る
RECIPE 03｜スタンプのセリフとポーズ
このキャラクターでLINEスタンプを8個作ります。
使う人は{保育園に子どもを通わせている、仕事をしているママ}です。
その人が毎日のLINEでよく送る言葉を8個選んで、
それぞれに合うポーズを考えてください。

・セリフは10文字以内
・「OK」「ありがとう」のような、どんな相手にも使える返事を2個入れる
・「見てね」と何かを指さしているポーズを1個入れる
・番号、セリフ、ポーズの順に、表にしてください

RECIPE04

スタンプの絵を、4つずつ作る

②LINEスタンプ販売

使い方

  1. 下の「コピーする」を押して、同じチャットで送ります。1枚の画像に、4つのポーズが並んで出てきます。
  2. ダウンロードしたら、{1番〜4番}を{5番〜8番}に書きかえて、もう一度送ります。
  3. 2枚の画像で、8個ぶんの絵がそろいます。

1枚に4つ並べてもらうのは、無料版の枚数の上限を節約するためです。2回送るだけで、販売できるいちばん少ない数の8個がそろいます。顔が変わってしまったときは「RECIPE 01のキャラクターと同じ顔に直して」と伝えてください。

同じチャットで、番号を書きかえて2回送る
RECIPE 04｜スタンプの絵を作る
同じキャラクターで、LINEスタンプ用のイラストを作ってください。
顔・体の形・色は変えないでください。

・1枚の画像の中に、ちがうポーズを4つ（たて2つ×よこ2つ）並べる
・ポーズ：さっきの表の{1番〜4番}
・ポーズどうしの間を広くあける
・文字は入れない（セリフはあとで自分で入れます）
・背景は透明にする（透過PNG）

②LINEスタンプ販売　Canvaと申請

Canvaでセリフを入れて、LINEに申請する

  1. Canvaの「カスタムサイズ」で、幅370×高さ320ピクセルのデザインを作ります。
  2. 4つ並んだ画像をアップロードして置き、ダブルクリックして、ポーズが1つだけ映るように切り抜きます。
  3. 「テキスト」でセリフを入れます。文字は大きく、太くします。
  4. ページを増やして、同じように8個作ります。
  5. 右上の「共有」→「ダウンロード」→「PNG」で、全部のページをダウンロードします。
  6. 背景が透明になっていないときは、Adobe Express（無料）の「背景を削除」に画像を入れて、透明にします。
  7. LINE Creators Marketにログインして「新規登録」→「スタンプ」を選び、タイトル・説明・画像を入れて申請します。
  • スタンプの画像：幅370×高さ320ピクセル以内、背景は透明のPNG、8個から
  • メイン画像：240×240ピクセル（8個の中から1つ選んで、サイズを変えて書き出す）
  • トークルームタブ画像：幅96×高さ74ピクセル
  • 申請の画面で、AIを使ったかどうかを正しく選ぶ

LINEスタンプは1セット120円から販売できて、作った人に入るのはそのうち35％ほどです。1セットで大きく稼ぐものではないので、ステッカーと同じ「置いておく収入」として育てていきます。サイズや決まりは変わることがあるので、申請の前にLINE Creators Marketの案内で確認してください。

RECIPE05

スライドの中身を、先に決めてもらう

③スライド制作

使い方

  1. 先に、ココナラで「スライド作成 Canva」と検索して、実績の多い方の見本を見ておきます。
  2. 下の「コピーする」を押して、ChatGPTに貼ります。
  3. { }の中を、作りたい資料の内容に書きかえて送ります。お客さんからもらった文章を、そのまま貼っても大丈夫です。
  4. 8ページぶんの見出しと本文が返ってきます。まるごとコピーします。

いきなりCanvaを開かず、中身を先に決めます。「1ページに伝えることは1つだけ」と書いておくと、文字がぎっしり詰まったスライドになりません。

同じチャットで続けて送る
RECIPE 05｜スライドの中身
スライド資料の構成を作ってください。

・何の資料か：{ピラティス教室の体験レッスンの案内}
・読む人：{運動が苦手な30〜40代の女性}
・伝えたいこと：{初心者でも安心／少人数／体験は1回1,000円}
・ページ数：8ページ
・1ページに伝えることは1つだけ
・ページごとに「見出し」と「本文（40文字まで）」を書く
・表やかざりの記号は使わず、そのままコピーできる文章にする

③スライド制作　Canvaで仕上げる

Canva AIで形にして、3か所だけ手直しする

  1. Canvaの左のメニューから「Canva AI」を開き、「デザイン」→「プレゼンテーション」を選びます。
  2. RECIPE 05でコピーした文章を貼りつけて送ります。数分で、8ページのスライドができます。
  3. 手直し1：色を、お店のイメージの色に変えます。
  4. 手直し2：見出しの文字を大きくします。
  5. 手直し3：写真を、お店に合うものに差しかえます。
  6. ポップにしたいときは、RECIPE 04で作ったちびキャラの「指さし」や「OK」のポーズを、ページのすみに置きます。
  7. 右上の「共有」→「ダウンロード」で、PDFかPowerPointの形式を選びます。
  • 1ページの文字が少なく、ぱっと見て意味が分かる
  • 色は2色か3色にしぼっている
  • ちびキャラは、表紙・大事なページ・最後のページの3か所くらいにしておく

お仕事は、ココナラに出品して待つ方法と、クラウドワークスで「スライド作成」「資料作成」「Canva」と検索して応募する方法があります。始める前に、教室・サロン・会社紹介の見本を3つ作っておくと、応募のときに一緒に送れます。

RECIPE06

商品名と説明文を作ってもらう

出品するとき

使い方

  1. 下の「コピーする」を押して、同じチャットに貼ります。
  2. { }の中を、売る場所と商品の内容に書きかえて送ります。
  3. 返ってきた商品名と説明文を、出品の画面に貼ります。自分の言葉に直したいところは、直して使います。

商品名は、買う人が検索しそうな言葉を前に並べるのがコツです。「著作権フリー」のような、言い切れない言葉は入れないでください。

同じチャットで続けて送る
RECIPE 06｜商品名と説明文
次の商品を{BOOTH}で販売します。商品名と説明文を作ってください。

・商品：{「赤ちゃんが寝ています」と書いた、玄関用のステッカー}
・買ってほしい人：{赤ちゃんのお昼寝中にインターホンで起こされて困っている人}
・商品名は、買う人が検索しそうな言葉を前に並べて、30文字以内
・説明文は、使う場面→サイズや素材→注意、の順で200文字くらい
・「著作権フリー」「必ず」「絶対」のような言葉は使わない

出品する前に

AIで作って売るなら、守ってほしい4つ

  • すでにあるキャラクターや、作家さんの名前を入れて作らない。似てしまったときは、モチーフや色を変えて作り直す。
  • 色だけ変えたものを大量に並べない。増やすときは、言葉や使い道を変える。
  • LINEスタンプの申請では、AIを使ったことを正直に選ぶ。
  • 商品の説明に「著作権フリー」と書かない。

副業の収入が増えたら、確定申告のときに住民税の納め方を「自分で納付」にしておくと、副業のぶんのお知らせが自宅に届きます。市区町村によって扱いが違うことがあるので、心配な方は申告の前に役所に確認してください。会社の副業のルールも、始める前に一度見ておきましょう。
