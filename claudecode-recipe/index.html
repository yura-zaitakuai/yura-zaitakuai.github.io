ゆらより

動画を見てくださって、ありがとうございます。公式LINEにも登録してくれて、本当にうれしいです。

Claude Codeは、教えたことや作ったものを、パソコンのフォルダに残して覚えておいてくれるAIです。私もこれを使い始めてから、リサーチと投稿づくりの時間が半分以下になりました。

いちばん大事なのは、RECIPE 00の「はじめの設定」です。ここで作るフォルダが、あなた専用のAIの「頭の中」になります。1つ終わるごとに「ここまでできた」にチェックを入れながら、進めてみてくださいね。

全体の地図

設定を1回したら、あとは3つの副業に使い回す

はじめる前に

Claude Codeを、パソコンに入れる

  1. claude.com を開いて、メールアドレスかGoogleアカウントでアカウントを作ります。
  2. 料金ページ（claude.com/pricing）で「Pro」を選んで、登録します。Claude Codeは無料プランでは使えません。
  3. claude.com/download から、自分のパソコン（WindowsかMac）用のアプリをダウンロードして、インストールします。
  4. アプリを開いてログインし、画面の左上にある「Code」をクリックします。
  5. パソコンの「ドキュメント」の中に、新しいフォルダを1つ作ります。名前は「在宅ワーク」など、なんでも大丈夫です。
  6. Codeの画面で、入力欄の下から「ローカル（Local）」を選び、「フォルダを開く」から、さっき作ったフォルダを選びます。
  • パソコン（Windows 10以降かMac）がある。スマホだけでは使えません
  • Claudeの有料プラン（Pro）に登録した
  • アプリの「Code」の画面で、作ったフォルダを開いた

料金の目安：いちばん安いProプランで月20ドル（日本円で3,000円くらい）。年払いにすると少し安くなります。2026年11月時点の金額なので、登録するときに公式ページでも確認してください。黒い画面（ターミナル）は使わなくて大丈夫です。

RECIPE00

作業場所と、あなたのことを覚えてもらう

最初に1回だけ

使い方

  1. 下の「コピーする」を押して、フォルダを開いたClaude Codeの入力欄に貼ります。
  2. { }の中の、家族・使える時間・ジャンルを、自分のことに書きかえて送ります。
  3. 「ファイルを作っていいですか？」と聞かれたら、内容を見て許可します。
  4. できあがった「わたしのこと」フォルダのエピソード.mdを開いて、見出しの下に自分のことを書いておきます。箇条書きで大丈夫です。

エピソード.mdは、RECIPE 04でnoteの記事を書くときの材料になります。AIは体験談や数字を作れないので、ここだけは自分で書いておくのがポイントです。慣れるまでは、ファイルを作る前に確認してくれるモードのまま使ってください。

ゆらの本音
ちゃんと自分の言葉で書いてほしいのですが、CLAUDE.mdの中身は書き方の見本として活用してください。ここに「私が体験していないことを書かない」と入れておくだけで、出てくる文章の安心感がぜんぜん変わります。

フォルダを開いたClaude Codeで送る
RECIPE 00｜はじめの設定
このフォルダを、私の在宅ワークの作業場所にしたいです。
次の3つをやってください。

1. このフォルダの中に「スレッズ」「note」「インスタ」「わたしのこと」「トンマナ参考」の5つのフォルダを作る
2. 「わたしのこと」フォルダに「エピソード.md」を作り、下の見出しだけを書いておく（中身は私があとで書きます）
   ・家族のこと
   ・今の働き方と、使える時間
   ・子育てで大変だったこと
   ・副業や仕事でうまくいかなかったこと
   ・うまくいったこと、うれしかったこと
3. このフォルダに CLAUDE.md を作り、下の内容を書き込む

---ここから CLAUDE.md の内容---
# このフォルダについて
スレッズ×楽天アフィリエイト、note、インスタの作業場所です。

# 私について
- 家族：{例：4歳と2歳の男の子のママ}
- 副業に使える時間：{例：平日は子どもが寝たあとの30分}
- スレッズのジャンル：{例：暮らし・家事がラクになるもの}
- noteのジャンル：{例：育児}

# 書き方のルール
- 一文は短く。むずかしい言葉は使わない
- 私が体験していないことを、体験したように書かない
- 実績・数字・体験談は作らない。分からないところは空けておいて、私に聞く
- 使っていない商品を「使ってよかった」と書かない
- 商品を紹介する投稿には、必ず「#PR」を入れる
- 「絶対」「誰でも」「必ず稼げる」は使わない

# 作業のしかた
- 作業を始める前に、何をするかを短く説明してから進める
- 何かを作るときは、先に「わたしのこと」と、そのジャンルのフォルダにあるリサーチ結果を読む
- 作ったものとリサーチ結果は、それぞれのフォルダに日付をつけて保存する

RECIPE01

スレッズで伸びている投稿をリサーチする

①スレッズ×楽天アフィリエイト

使い方

  1. 下の「コピーする」を押して、Claude Codeに貼ります。
  2. { }のジャンルを書きかえて送ります。今回の例は「暮らし・家事がラクになるもの」です。
  3. Claude Codeがスレッズを見て、表にまとめてくれます。そのあいだは待っているだけで大丈夫です。
  4. うまく見られなかったときは、自分で「伸びているな」と思った投稿のスクショを「スレッズ」フォルダに入れて、「この投稿が伸びている理由を分析して保存して」と送ります。

見てほしいのは、表示回数がフォロワー数の何倍になっているかです。フォロワーが少ないのに見られている投稿は、中身そのもので伸びているので、マネする価値があります。

ゆらの本音
私も、このリサーチを自分の手でやっていたころは、ここだけで何十分もかかっていました。今は毎朝、伸びている投稿の一覧が届くようにしています。慣れてきたら「毎朝このリサーチをして」とお願いしてみてください。

Claude Codeで送る
RECIPE 01｜スレッズのリサーチ
スレッズで、{暮らし・家事がラクになるもの}のジャンルの投稿の中から、
フォロワー数よりも表示回数がずっと多い投稿を10件探して、表にまとめてください。

表に入れるもの：
・投稿の書き出し（最初の1〜2行）
・表示回数、いいねの数、フォロワー数
・表示回数がフォロワー数の何倍か
・どんな型の投稿か（質問型／体験談型／比較型／まとめ型 など）

表のあとに、伸びている投稿の共通点を3つまとめてください。
できたものは「スレッズ」フォルダに「リサーチ_今日の日付」という名前で保存してください。
スレッズの画面がうまく見られないときは、無理に進めずに私に教えてください。

RECIPE02

リサーチをもとに、楽天の商品つきで投稿を作る

①スレッズ×楽天アフィリエイト

使い方

  1. RECIPE 01のあと、同じClaude Codeで送ります。
  2. { }に、紹介したい商品のジャンルを書きます。
  3. 3パターンの投稿と、おすすめの楽天市場の商品が出てきます。
  4. 使う投稿を1つ選んで、自分の言葉に直します。
  5. 商品のリンクは、楽天アフィリエイトのページで作った「自分用のリンク」に差しかえて、リプに貼ります。

Claude Codeが出してくれるのは、ふつうの商品ページのURLです。そのまま貼っても報酬にはならないので、必ず楽天アフィリエイトで自分用のリンクを作ってください。楽天アフィリエイトの登録とリンクの作り方は、チャンネルの1本目の動画で画面を見せながらお話ししています。

ゆらの本音
最初から完璧な投稿は出てきません。伸びた投稿を「スレッズ」フォルダに入れて「これが伸びた」と伝えていくと、だんだん自分のアカウントに合った投稿が出てくるようになります。

RECIPE 01と同じClaude Codeで送る
RECIPE 02｜楽天つきの投稿
「スレッズ」フォルダにある、いちばん新しいリサーチ結果を読んでください。
その中でいちばん伸びていた型を使って、楽天市場で買える{家事がラクになるキッチングッズ}を紹介するスレッズの投稿を、3パターン作ってください。

作り方のルール：
・本投稿は500字以内。1行目は、続きが読みたくなる言葉にする
・本投稿では商品名を出さずに、自分の返信（リプ）で商品を紹介する
・リプには必ず「#PR」を入れる
・「わたしのこと」と、これまで保存した投稿の書き方に合わせる
・私が使っていない商品は「気になっている」「調べたら見つけた」という書き方にする

おすすめする楽天市場の商品は、1パターンにつき1つ選んで、
商品名・ショップ名・値段・レビューの数と点数・商品ページのURL・選んだ理由を、一緒に出してください。
レビューが少ないものや、相場より極端に安いものは選ばないでください。

できた投稿は「スレッズ」フォルダに「投稿_今日の日付」という名前で保存してください。

①スレッズ　投稿する前に

この5つを確かめてから投稿する

  1. 投稿を1つ選んで、スレッズに貼ります。
  2. 商品を紹介するリプに、自分用の楽天のリンクを貼ります。
  3. 伸びたら、その投稿の文章と表示回数を「スレッズ」フォルダに入れておきます。
  • リプに「#PR」が入っている
  • 使ったことのない商品なのに「使ってよかった」と書いていない
  • 値段やレビューの数を、楽天のページで自分の目で確かめた
  • リンクを、自分用のアフィリエイトリンクに差しかえた
  • 楽天アフィリエイトの「サイト情報」に、自分のスレッズを登録した

楽天アフィリエイトは、1件売れて入るのが数十円から100円くらいのことが多いです。だからこそ、投稿の量を出すところをAIに任せるのがおすすめなんです。

RECIPE03

noteで読まれている育児の記事をリサーチする

②note

使い方

  1. 下の「コピーする」を押して、Claude Codeに貼ります。
  2. { }のジャンルは、今回の例では「育児」です。自分が書きたいジャンルに変えても大丈夫です。
  3. 表と、読まれている記事の共通点、まだ少ないテーマが返ってきます。

いちばん使えるのは「まだ少ないテーマ」です。読まれている型で、まだ書かれていないテーマを書くと、ほかの記事と比べられにくくなります。ほかの人の文章をそのまま使うのはNGです。

Claude Codeで送る
RECIPE 03｜noteのリサーチ
noteで、{育児}のジャンルで今読まれている記事を10本探して、表にまとめてください。
noteの検索・ハッシュタグ・おすすめに出ている記事の中から、スキの数が多いものを選んでください。

表に入れるもの：
・タイトル、スキの数、有料か無料か（有料なら値段）
・どんな悩みに答えている記事か
・タイトルの付け方の型（数字入り／体験談／ビフォーアフター など）
・見出しの流れ（ざっくりでOK）

表のあとに、次の2つをまとめてください。
・読まれている記事の共通点を3つ
・まだ書かれていない、または少ないテーマを3つ

記事の文章をそのまま写すことはせず、型と共通点だけを書いてください。
できたものは「note」フォルダに「リサーチ_今日の日付」という名前で保存してください。

RECIPE04

リサーチと自分のエピソードで、記事を書く

②note

使い方

  1. 先に、「わたしのこと」フォルダのエピソード.mdに、自分のことを書いておきます。
  2. 下の「コピーする」を押して、Claude Codeに貼ります。
  3. { }のテーマと、読んでほしい人を書きかえて送ります。
  4. 記事と、最後に「聞きたいこと」が出てきます。答えを送ると、空いていたところを埋めてくれます。
  5. 最後は自分で読み直して、自分の言葉に直してから、noteに貼ります。

記事の中心は、AIではなくあなたのエピソードです。AIには、型と書き方を手伝ってもらいます。エピソード.mdに書いたことが増えるほど、あなたらしい記事になっていきます。

ゆらの本音
noteは、値段を自分で決められるのがいちばんの強みです。最初の1本が売れるまでは時間がかかることもあるので、まずは無料の記事を何本か出して、読んでくれる人を増やしていくのがおすすめです。

RECIPE 03と同じClaude Codeで送る
RECIPE 04｜noteの記事
「note」フォルダのいちばん新しいリサーチ結果と、「わたしのこと」フォルダのエピソード.mdを読んでください。
そのうえで、私のエピソードを中心にしたnoteの記事を1本書いてください。

テーマ：{リサーチで出てきた「まだ少ないテーマ」の1つ目}
読んでほしい人：{例：保育園からの呼び出しで仕事を休むたびに、落ち込んでしまうママ}

書き方のルール：
・最初に、読んでほしい人の悩みを、場面が浮かぶように書く
・真ん中は、私のエピソードと、そこから分かったことを書く
・最後に、読んだ人が明日からできることを1つ書く
・タイトル案を3つ。見出しは4〜6個
・リサーチで分かった「読まれている記事の型」を使う。ただし、ほかの人の文章は写さない
・エピソード.mdに書いていない出来事や数字は作らない。足りないところは【ここに〇〇のエピソード】と空けておく

書き終わったら、私に聞きたいこと（エピソードの足りないところ）を、最後に3つまで書いてください。
できた記事は「note」フォルダに「記事_今日の日付」という名前で保存してください。

RECIPE05

ChatGPTの画像生成とつないで、記事の画像を作る

②note　画像

使い方

  1. 下の「コピーする」を押して、Claude Codeに貼って送ります。
  2. 「参考の画像を送ってください」と言われたら、これまで自分が作ってきた画像（アイコン・見出し画像・投稿の画像など）を「トンマナ参考」フォルダに入れて、「入れました」と送ります。
  3. トンマナ.md（色や雰囲気のまとめ）ができたら、中身を読んで、違うところがあれば伝えます。
  4. OpenAIのサイト（platform.openai.com）でAPIキーを作り、Claude Codeが作った .env ファイルを自分で開いて、キーを貼って保存します。
  5. 「入れました」と送ると、見出し画像と図解を作って、「note」フォルダの「画像」フォルダに保存してくれます。

トンマナというのは、色やデザインの雰囲気のことです。自分が作ってきた画像を見本に渡すと、毎回同じ雰囲気の画像になるので、記事を並べたときに「この人の記事だ」と分かってもらいやすくなります。APIキーは、パスワードと同じくらい大事なものです。チャットに貼ったり、人に見せたりしないでください。

Claude Codeで送る
RECIPE 05｜画像をAPIで作る
noteの記事に入れる画像を、ChatGPTと同じOpenAIの画像生成（API）を使って作れるようにしたいです。
次の順番で、1つずつ進めてください。

1. まず私に、トンマナ（色やデザインの雰囲気）の参考にしたい画像を送るように言ってください。
   私がこれまでに作ってきた画像（アイコン、見出し画像、投稿の画像など）を「トンマナ参考」フォルダに入れるので、入れ終わったと私が言うまで待ってください。
2. 入れ終わったら、その画像を見て、色・文字の雰囲気・イラストのタッチ・余白の取り方を、「トンマナ参考」フォルダの「トンマナ.md」にまとめてください。
3. OpenAIの画像生成APIを使う準備をしてください。
   ・使うモデルは、OpenAIの公式ドキュメントで、今いちばん新しい画像生成モデルを確かめて選ぶ
   ・APIキーは私が自分で入れるので、入れる場所（.envファイル）だけを作って、入れ方を説明する。キーをこのチャットに貼るようには言わない
4. 準備ができたら、「note」フォルダのいちばん新しい記事を読んで、
   見出し画像を1枚と、記事の途中に入れる図解を2枚、トンマナ.mdに合わせて作り、「note」フォルダの中の「画像」フォルダに保存してください。
5. 1枚作るごとに、だいたいいくらかかったかも教えてください。

②note　画像　お金のこと

APIの料金は、ChatGPTの月額とは別にかかります

  1. OpenAIのAPIは、使った分だけ払うしくみです。先にチャージ（クレジットの購入）をしてから使います。
  2. 1枚あたりの金額は、画像の大きさや画質で変わります。RECIPE 05では、1枚作るごとに金額を教えてもらうようにしています。
  3. まずは少しだけチャージして、何枚か作ってみてから続けるか決めるのがおすすめです。
  • ChatGPTの有料プランに入っていても、APIの料金は別にかかると分かった
  • 使いすぎないように、チャージは少なめから始める
  • APIキーを、チャットや人に見せる場所に貼っていない

料金やモデルの名前は、よく変わります（2026年11月時点）。使う前に、OpenAIの公式の料金ページで確かめてください。お金をかけずに試したいときは、下のRECIPE 06を使ってください。

RECIPE06

APIを使わずに、ChatGPTに貼るプロンプトを作ってもらう

②note　画像（お金をかけずに）

使い方

  1. RECIPE 05の1と2（トンマナ参考の画像を入れて、トンマナ.mdを作る）までは同じように進めます。
  2. 下の「コピーする」を押して、Claude Codeに貼って送ります。
  3. 出てきた3つのプロンプトを、1つずつChatGPTに貼って、画像を作ってもらいます。
  4. できた画像を、noteの記事に入れます。

Claude Codeがトンマナに合わせたプロンプトを書いてくれるので、ChatGPTに毎回「こういう雰囲気で」と説明しなくて大丈夫です。ChatGPTの無料版は、1日に作れる画像の枚数に上限があります。

Claude Codeで送る
RECIPE 06｜画像のプロンプト
「note」フォルダのいちばん新しい記事と、「トンマナ参考」フォルダのトンマナ.mdを読んでください。
ChatGPTに貼って画像を作ってもらうためのプロンプトを、3つ書いてください（見出し画像を1枚、図解を2枚）。
・トンマナ.mdの色と雰囲気に合わせる
・画像の中に入れる文字は短くして、プロンプトの中にそのまま書く
・見出し画像は横長（noteの見出し画像の比率）にする

RECIPE 07　③インスタ

インスタの動画づくりのレシピは、ただいま準備中です

動画でお話ししたように、インスタは私がいちばんおすすめしている副業です。いちばんのハードルだった動画の編集まで、Claude Codeが手伝ってくれます。実際の画面に合わせて、受け取ってくれた方がそのまま使えるプロンプトを準備しています。できしだい、このページに追加しますね。

さいごに

最後に、正直にお伝えしたいところ

ここまでで、Claude Codeを動かす準備はそろいました。ただ、Claude Codeは、入れたばかりだと「何も知らない新人さん」です。最初に何を覚えさせるか、誰のやり方を入れておくかで、出てくるものがまったく変わります。

このページのレシピは、その入口です。実際に私たちが使っているやり方や、あなたの生活や使える時間に合う組み合わせは、一人ひとり違います。それに、1人で続けるのは、思っている以上に大変なんですよね。
